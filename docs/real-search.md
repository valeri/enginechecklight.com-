# EngineCheckLight — რეალური ძებნა

## სად არის კოდი

ცალკე Netlify ფუნქცია არ არის: ძიება არსებულ `/api` router-შია ჩართული, რომ მომხმარებლის ამოცნობა, ლიმიტი და Blobs store ერთი იყოს.

| ფაილი | როლი |
| --- | --- |
| `src/research/diagnose.mjs` | ძიების ლოგიკა (`step: basic / research`) |
| `src/research/lib/dtc.mjs`, `sources.mjs`, `nhtsa.mjs` | კოდის გაშიფვრა, წყაროების დონეები, NHTSA |
| `src/app.js` → `POST /api/check` | კრედიტები (დღიური შემოწმებები), ცოდნის ბაზა (`kb:` key-ები `ecl` store-ში), ისტორია |
| `public/index.html` | UI: `diagnoseBasic`, `diagnoseResearch`, `TIER_LABEL` |
| `test/run.mjs`, `test/research.test.js` | ტესტები |

## გაშვება

1. `@netlify/blobs` უკვე დაყენებულია.
2. Netlify → Site configuration → Environment variables: `ANTHROPIC_API_KEY`.
   სურვილისამებრ `ANTHROPIC_MODEL` (ნაგულისხმევი: `claude-sonnet-5-5`).
3. Claude Console-ში ვებ-ძიება ჩართული უნდა იყოს ორგანიზაციისთვის.
4. `node test/run.mjs` — ტესტები (ქსელის გარეშე, მოკებით).
5. `npm run dev` და შემდეგ:

```bash
curl -X POST localhost:8888/api/check \
  -H 'content-type: application/json' \
  -d '{"step":"research","code":"B143C-11","make":"Land Rover","model":"Range Rover Sport","year":"2016","lang":"ka"}'
```

## როგორ მუშაობს

**`step: "basic"`**: მყისიერი, უფასო, AI-ის გარეშე. აბრუნებს კოდის ზუსტ სტრუქტურას, სუფიქსის მნიშვნელობას (მაგ. `-11` = Circuit short to ground) და NHTSA-ს გამოძახებებსა და საჩივრებს.

**`step: "quick"`**: სწრაფი ძიება, Claude-ის ერთი გამოძახება, მაქსიმუმ 3 ძიებით და 45-წამიანი ლიმიტით (Netlify-ის 60 წამში ეტევა). ღია ვებში ეძებს, მაგრამ prompt ოფიციალურ წყაროებს ანიჭებს უპირატესობას. შემოწმებას ხარჯავს **მხოლოდ თუ განმარტება იპოვა**. თუ ვერ იპოვა ან შეცდომა მოხდა, პასუხში მოდის `can_extend: true` და UI მომხმარებელს გაფართოებულ ძიებას სთავაზობს.

**`step: "research"`**: გაფართოებული ძიება background job-ად. `POST` → `202 { jobId }`, შემდეგ UI ყოველ 4 წამში კითხულობს `GET /api/check/<jobId>`-ს. ორი ეტაპია: **A** მხოლოდ ოფიციალურ დომენებზე, **B** ღია ვებზე, თუ A-მ არ იკმარა. ოფიციალური განმარტება ყოველთვის იმარჯვებს. შემოწმება წარმატების შემთხვევაში იხარჯება. Netlify-ზე job-ს უშვებს `netlify/functions/research-background.mjs` (ლიმიტი 15 წუთი), ლოკალურად კი იგივე პროცესი. job-ის მონაცემები store-დან იკითხება, ამიტომ background ფუნქციის პირდაპირ გამოძახება გამოგონილი id-ით არაფერს აკეთებს. შედეგს მხოლოდ მისი მფლობელი ხედავს.

## სიზუსტის დაცვა

- მოდელს ეკრძალება მწარმოებლის კოდის მეხსიერებიდან გამოცნობა; თუ წყარო ვერ იპოვა, `definition.found = false`.
- ყველა URL მოწმდება: რჩება მხოლოდ ის, რაც ძიებამ რეალურად დააბრუნა. გამოგონილი ბმული იშლება.
- ყველა წყაროს აქვს `tier`: `official_government`, `official_manufacturer`, `official_standard`, `professional`, `community`.
- `confidence: "high"` მხოლოდ მაშინ, როცა განმარტება ოფიციალური წყაროდანაა.

## ხარჯი და კრედიტები

- პასუხში მოდის `usage`: ტოკენები და ძიებების რაოდენობა. ამით დაითვლი ერთი შემოწმების რეალურ ფასს.
- ცოდნის ბაზა (Netlify Blobs): იგივე კოდი + იგივე მანქანა მეორედ AI-ს აღარ იძახებს (`cached: true`).
- კრედიტები (`src/credits.js`, `src/packs.js`): 1 კრედიტი = ერთი კოდი. სწრაფი ძიება ხარჯავს 1 კრედიტს, და თუ განმარტება ვერ იპოვა, იმავე კოდის გაფართოებული ძიება 24 საათის განმავლობაში ამ კრედიტშივე შედის. cache და შეცდომა უფასოა.
- ხარჯის დაცვა (`src/research/cost.mjs`): სწრაფი ძიების ზღვარი $0.18, გაფართოებულის $0.30. ზღვარს მიღწეული ძიება ჩერდება. დღიური ჯამური ლიმიტი: `DAILY_SPEND_LIMIT_USD`. პაკეტის ფასი ვერ იქნება 50%-იან მარჟაზე ნაკლები ყველაზე ცუდ შემთხვევაშიც.

## რა არ არის შემოწმებული

- რეალური გამოძახება Anthropic API-ზე და NHTSA-ზე (ტესტები მოკებით გადის).
- Netlify Blobs რეალურ გარემოში.
- ფუნქციის დროის ლიმიტი: ორეტაპიანმა ძიებამ შეიძლება Netlify-ს სინქრონული ფუნქციის ლიმიტს გადააცილოს. თუ ასე მოხდა, შემდეგი ნაბიჯია background function + შედეგის გამოკითხვა.
- `sources.mjs`-ის დომენების სია საწყისია; თუ API რომელიმე დომენს უარყოფს, ეტაპი A გამოტოვდება და ეტაპი B იმუშავებს.

## შეზღუდვები

- მწარმოებლის ოფიციალური სერვის-ინფორმაცია (JLR TOPIx, VAG erWin) ფასიანი და დახურულია; ღია ძიება მას ვერ კითხულობს.
- NHTSA აშშ-ის ბაზრის მანქანებს ფარავს.
- სუფიქსების ცხრილი გადაამოწმე SAE J2012-DA-სთან გაშვებამდე.
